    Setup

    Start a local Chrome for the default browser once:

    google-chrome --remote-debugging-port=9222 --user-data-dir=/tmp/jev-chrome

    Then run the server:

    jev-server

    Environment knobs:

    • JEV_BROWSER=cloud with BROWSER_USE_API_KEY for cloud browsers.
    • JEV_SERVER_TOKEN requires a bearer token on every API call.
    • JEV_SESSION_IDLE_MIN (default 10) closes idle session browsers.
    • JEV_CLOUD_SHOW_LIVE_URL=1 embeds the cloud live view.
    • JEV_AGENT=new (default) runs the Beam loop; classic keeps TypeSafe+Mercury.
    • JEV_MODEL (default Beam-1.0-501B-A23B) and JEV_REASONING_EFFORT (low–max).

    Keys stay in .env on the server. They are never shown here.
